# COD-001：代收货款 — 设计方案

- 状态：已确认
- 日期：2026-11-17
- 关联：ROADMAP P8；AGENTS.md §6.5（COD 独立资金，追加式，冲正保留原+反向）；WB-001（cod_amount/cod_status）

## 1. 业务目标

COD 独立资金闭环：运单确认后自动创建 COD 订单（金额 = waybill.CodAmount）；目的网点交付时登记 COD 收款（追加式）；发货人结算（不允许超额）；付款给发货人。**COD 与运费财务完全分离**（AGENTS §6.5）。

## 2. 领域规则

- **COD 订单**：运单确认时懒创建（金额 = waybill.CodAmount，仅 >0 时创建）。状态：PendingCollection → Collected → Settled → PaidOut。
- **收款（CodCollection，追加式）**：目的网点收款；累计 ≤ 订单金额；不允许超额收款；多次收款。
- **结算（CodSettlement）**：发货人应付余额 = 已收金额；结算单按发货人生成；不允许超额结算（结算金额 ≤ 已收-已付）。状态：Draft → Approved → PaidOut。
- **冲正**：追加式反向记录。
- COD 金额不计入物流运费收入（运单 TotalAmount 不含 COD）。

## 3. 表结构

```sql
CREATE TABLE cod_orders (
    id uuid PK, tenant_id uuid NOT NULL, waybill_id uuid NOT NULL,
    amount numeric(18,2) NOT NULL CHECK (> 0),
    collected_amount numeric(18,2) NOT NULL DEFAULT 0 CHECK (>= 0),
    settled_amount numeric(18,2) NOT NULL DEFAULT 0 CHECK (>= 0),
    paid_amount numeric(18,2) NOT NULL DEFAULT 0 CHECK (>= 0),
    status smallint NOT NULL,  -- 1=PendingCollection 2=Collected 3=Settled 4=PaidOut
    created_at/by, updated_at/by, xmin, ux (tenant_id, waybill_id)
);
CREATE TABLE cod_collections (
    id uuid PK, tenant_id uuid NOT NULL, cod_order_id uuid NOT NULL,
    amount numeric(18,2) NOT NULL CHECK (> 0),
    operator_user_id uuid NULL, note varchar(500) NULL,
    occurred_at timestamptz NOT NULL, created_at timestamptz NOT NULL
);
CREATE TABLE cod_settlements (
    id uuid PK, tenant_id uuid NOT NULL, cod_order_id uuid NOT NULL,
    amount numeric(18,2) NOT NULL CHECK (> 0),
    status smallint NOT NULL,  -- 1=Draft 2=Approved 3=PaidOut
    approved_by uuid NULL, approved_at timestamptz NULL,
    paid_by uuid NULL, paid_at timestamptz NULL,
    operator_user_id uuid NULL, created_at/by, xmin
);
```

## 6. 验收标准

- [ ] COD 金额不计入物流运费收入（Receivable 不含 COD，代码层面验证）。
- [ ] COD 收取、待结算、已结算金额能够核对（实测）。
- [ ] 不允许超额结算（实测 409）。
- [ ] 付款经过审批（实测：先 approve 再 pay，跳过 approve → 409）。
- [ ] COD 流水追加式（实测）。
