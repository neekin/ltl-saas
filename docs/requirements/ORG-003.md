# ORG-003：组织管理 API、权限校验与审计日志 — 设计方案

- 状态：已确认（自保护规则与审计粒度为第一版，见 §5/§6）
- 日期：2026-11-17
- 关联：ROADMAP P1（租户/网点/用户/角色管理、审计日志）；AGENTS.md §5.2/§8；AUTH-001（认证基线）；ORG-001/002（模型与授权服务）；ADR-0005

## 1. 业务目标

交付首批**受保护的业务 API**：网点、员工、角色的管理端点（权限点实时校验）+ 关键写操作审计日志。AUTH-001 已建立认证管道；本任务建立"认证 → 权限 → 业务 → 审计"的完整服务端授权样板，供后续所有模块端点复用。

## 2. 范围

- **交付**：`/api/organization/*` 端点（网点/员工/角色管理）、服务端权限校验（`organization.*` 权限点实时查库）、审计日志（追加式）、403 语义、分页约定。
- **不交付**（明确排除）：
  - 租户生命周期管理（创建/启停用租户）——需要**平台管理员**身份概念与租户引导策略，属独立设计决策，列为后续任务 TEN-002；当前租户由运维/种子数据建立；
  - 密码修改自助端点（改密走管理员重置，自助改密后续任务）；
  - 账户失败锁定/防爆破（AUTH-001 已声明边界）。

## 3. 端点契约（均需认证；权限点实时校验，禁用即时生效）

| 端点 | 权限点 | 说明 |
|------|--------|------|
| `GET /api/organization/branches?page&pageSize` | branch.read | 分页列表 |
| `GET /api/organization/branches/{id}` | branch.read | 详情 |
| `POST /api/organization/branches` | branch.manage | 创建（code/name） |
| `PUT /api/organization/branches/{id}` | branch.manage | 重命名 |
| `POST /api/organization/branches/{id}/disable` · `/enable` | branch.manage | 启停用（幂等） |
| `GET /api/organization/users?page&pageSize` | user.read | 分页列表 |
| `GET /api/organization/users/{id}` | user.read | 详情（含角色、网点范围、租户级范围） |
| `POST /api/organization/users` | user.manage | 创建（密码经 PasswordPolicy + PasswordHasher） |
| `PUT /api/organization/users/{id}/name` | user.manage | 改显示名 |
| `POST /api/organization/users/{id}/reset-password` | user.manage | 重置密码（密码策略） |
| `POST /api/organization/users/{id}/disable` · `/enable` | user.manage | 启停用（幂等；**禁止禁用自己** §5） |
| `PUT /api/organization/users/{id}/roles` | user.manage | 设置角色集合（增删差量） |
| `PUT /api/organization/users/{id}/branch-scopes` | user.manage | 设置网点范围集合（增删差量） |
| `POST /api/organization/users/{id}/tenant-wide-scope` · DELETE | user.manage | 授予/收回租户级范围 |
| `GET /api/organization/roles?page&pageSize` | role.read | 分页列表（含权限点） |
| `GET /api/organization/roles/{id}` | role.read | 详情 |
| `POST /api/organization/roles` | role.manage | 创建 |
| `PUT /api/organization/roles/{id}` | role.manage | 重命名 |
| `POST /api/organization/roles/{id}/disable` · `/enable` | role.manage | 启停用（幂等） |
| `PUT /api/organization/roles/{id}/permissions` | role.manage | 设置权限点集合（限平台清单内） |

- 统一分页：`page`（1 起）、`pageSize`（1..100，默认 20）→ `{items, total, page, pageSize}`。
- 错误语义：未认证 401（AUTH-001）；无权限点 **403 ProblemDetails**（`PermissionDeniedException`）；实体不存在/跨租户 **404**（`EntityNotFoundException`）；参数违规 400（领域 ArgumentException → GlobalExceptionHandler 映射现有语义）。
- 审计值（actor_user_id）来自 JWT `sub` claim，**服务端解析**，不信任 Body。

## 4. 架构

- 端点为薄壳：解析当前用户（claims）→ 调用模块 Application 服务。
- **权限校验在服务层**（非端点中间件）：任何调用方（API、后台任务）过同一校验；`HasPermissionAsync` 实时查库（ORG-002 禁用即时生效语义）。
- 授权变更命令**复用 ORG-002 `AuthorizationService`**（不重写）；本任务新增管理查询与差量设置。
- 领域补齐：`Branch.Rename` / `Role.Rename` / `User.Rename`（幂等守卫不变）。

## 5. 自保护规则（第一版）

- 操作者**不能禁用自己的账号**（防自锁；403/400 语义拒绝）。
- 收回自己的角色/范围：第一版**允许**（不致锁死账号本身，且有其他管理员时安全）；是否限制待业务确认，文档记录。
- 租户级范围授予/收回、重置密码等高危操作全部落审计。

## 6. 审计日志（Platform 模块，追加式）

```sql
CREATE TABLE audit_logs (
    id uuid PRIMARY KEY,
    tenant_id uuid NOT NULL REFERENCES tenants(id),
    occurred_at timestamptz NOT NULL,
    actor_user_id uuid NULL,          -- 审计值拷贝（不建外键，同 waybill_events 语义）
    action varchar(100) NOT NULL,     -- "organization.branch.create" 等
    entity_type varchar(64) NOT NULL, -- "branch" / "user" / "role"
    entity_id uuid NULL,
    detail jsonb NULL,                -- 操作摘要（编码/名称等，不含敏感值如密码哈希）
    created_at timestamptz NOT NULL
);
CREATE INDEX ix_audit_logs_tenant_occurred ON audit_logs (tenant_id, occurred_at DESC);
```

- **原子性**：业务保存与审计写入经 `TransactionScope`（两 DbContext 同库，环境事务 enlist）——审计失败则业务回滚，业务失败审计不落（AGENTS §4.3 同库强一致）；集成测试验证回滚路径。
- `detail` 不含密码哈希/令牌等敏感值（AGENTS §11）。

## 7. 测试计划（集成为主，WebApplicationFactory + Testcontainers）

1. 权限矩阵：无权限点调用管理端点 → 403；有权限点 → 200；禁用角色后权限即时失效 → 403（ORG-002 语义端到端）。
2. 未认证 → 401（既有基线）。
3. 网点：创建/重命名/启停用 + 分页；同租户重名 409 冲突（唯一索引）。
4. 用户：创建（密码策略校验：弱密码 400）、重置密码、改显示名、禁用后登录/刷新失效、**禁用自己被拒**。
5. 角色授权：设置角色集合/网点范围/租户级范围/权限点集合（差量生效、幂等）；被授权用户经 `/api/auth/me` 可见权限变化。
6. 审计：关键写操作各落一行（action/entity/actor/detail 正确）；业务失败（重名冲突回滚）→ **无审计残留**（同事务验证）。
7. 跨租户访问（他租户实体 Id）→ 404。
