# WB-002：开单、计价快照和运单事件 — 设计方案

- 状态：已确认（幂等键/审计字段的交付边界见 §2/§6）
- 日期：2026-11-17
- 关联：ROADMAP P4/WB-002；AGENTS.md §6.1（状态事件）、§6.4（计价快照）、§8（关键命令幂等）；SEQ-001（单号）；PRICE-002（试算）；WB-001（运单模型）

## 1. 业务目标

交付运单的**开单命令**（含计价调用与固化、幂等）、**确认/取消命令**、**计价快照持久化**与**运单事件时间线**。开单即 ROADMAP 场景 A 的起点：一票运单创建后，费用由计价引擎产生并保存价格快照，关键状态变化可追溯。

## 2. 开单命令流程（Waybills 模块 Application，单事务）

```text
CreateWaybillAsync(command)
 1. 租户上下文（fail-closed）
 2. 幂等键命中？→ 返回已存在运单（不重复开单/收费）
 3. 跨模块校验（原生 SQL + 显式租户参数，AGENTS §5.1；CUS-001 先例）：
    始发/目的网点存在且启用（取得网点码，供单号组装，不信任客户端）、客户存在且启用、线路（如给）存在且启用
 4. 计价试算：IPricingTrialService.TrialCalculateAsync(规则集, 输入{Σ件数/重量/体积, 客户/线路/网点})
    —— 输入由货物件汇总计算；试算失败（停用/无版本/无匹配）→ 明确报错，不消耗单号（先试算后取号）
 5. 取运单号：IBranchSequenceService（SEQ-001，YB+网点码+期间+6 位序号）
 6. Waybill.Create（草稿）+ ApplyPricing(quote.Total)（仅 Draft 一次性固化，WB-001 守卫）
 7. 落计价快照（§3）+ 落"开单"事件（§4）→ SaveChanges（同事务）
```

- 确认/取消命令：加载（租户过滤器）→ WB-001 状态机守卫 → 状态变更与事件**同一事务**写入（AGENTS §4.3：不拆异步）。
- 操作人/操作网点：命令参数（审计值）；认证交付后改由服务端租户/身份上下文解析（AGENTS §5.1 不信任客户端的原则届时收紧）。

## 3. 计价快照（append-only，AGENTS §6.4）

```sql
CREATE TABLE waybill_pricing_snapshots (
    id uuid PK,
    tenant_id uuid NOT NULL,          -- FK → tenants(id)
    waybill_id uuid NOT NULL,         -- 复合外键 → waybills(tenant_id, id)
    rule_set_id uuid NOT NULL,        -- 快照值，不建跨模块外键（PRICE-001 §4 同理：历史与规则生命周期解耦）
    rule_set_code varchar(64) NOT NULL,
    version_id uuid NOT NULL, version_number int NOT NULL,
    input jsonb NOT NULL,             -- PricingQuoteInput 快照（Σ件数/重量/体积 + 客户/线路/网点）
    quote jsonb NOT NULL,             -- PricingQuoteResult 快照（命中规则、逐项明细、折扣、小计/总额）
    created_at/by
);
```

- 追加式：不更新、不删除；重新计价为显式业务操作（追加新快照），本期未交付重算命令（ROADMAP P4 修改规则任务随修改一并交付），WB-001 守卫已保证已固化费用不可覆盖。
- JSON 序列化经 Pricing 公开接口 `IPricingSnapshotSerializer`（Pricing.Application，内部用 ADR-0007 的强类型选项），Waybills 不引用 Pricing Infrastructure。

## 4. 运单事件（AGENTS §6.1）

```sql
CREATE TABLE waybill_events (
    id uuid PK, tenant_id uuid NOT NULL, waybill_id uuid NOT NULL,   -- 复合外键
    event_type smallint NOT NULL,     -- 1=开单 2=确认 3=取消  ck
    branch_id uuid NULL,              -- 操作网点（审计值拷贝，不建外键：网点/用户只停用不删除，
    operator_id uuid NULL,            --   审计快照语义保持历史可追溯）
    from_status smallint NULL, to_status smallint NULL,   -- ck IN (1,2,3)（运单状态）
    occurred_at timestamptz NOT NULL, detail varchar(500) NULL
);
```

- 首批事件：开单（→Draft）、确认（Draft→Confirmed）、取消（→Cancelled）；查询按时间正序（时间线）。

## 5. 幂等（AGENTS §8）

- 命令携带 `IdempotencyKey`（Guid，可空）：命中 `(tenant_id, idempotency_key)` → 返回已存在运单；
- 部分唯一索引兜底并发竞态（23505 → 回查返回已有运单），重复提交不产生重复运单或重复收费；
- 未携带幂等键的请求按普通创建处理。

## 6. 交付边界（如实说明）

- 无 HTTP 端点（认证交付后随登录任务暴露）；
- 运单修改（改草稿资料/货物件后重算）不在本任务（WB-001 已建模 Draft 调整守卫）；
- 收货登记/入库/分拣、打印数据接口属 P4 后续任务。

## 7. 测试计划（集成为主，Testcontainers）

1. 开单全流程：有效网点/客户/已发布规则集 → 运单落库（单号格式 YB+网点码+期间+序号、总费用=试算总额）+ 快照 1 行（input/quote 可回读、版本引用正确）+ 事件"开单"。
2. 幂等：同键重复调用返回同一运单（仅 1 行、不重复收费）；并发同键 → 唯一索引兜底后回查一致。
3. 停用网点/他租户客户（原生 SQL 租户校验）→ 明确报错且不落任何数据。
4. 无已发布规则集 / 无匹配规则 → 明确报错（不静默计零、不产生运单）。
5. 确认/取消：状态迁移 + 事件前后状态正确；重复确认/重复取消拒绝；确认后货物件调整拒绝（WB-001 守卫）。
6. 事件时间线按时间正序且含操作人/网点/说明。
7. 跨租户访问运单（确认他租户运单）→ EntityNotFoundException。
8. 快照 input 精度往返（12.345 kg）。

## 8. 验收标准

- [ ] 运单费用由计价引擎产生，保存规则版本 + 输入 + 明细快照（P4 验收）。
- [ ] 重复提交（幂等键）不生成重复运单或重复收费（实测）。
- [ ] 开单/确认/取消事件含租户、运单、网点、操作人、时间、前后状态（实测）。
- [ ] 试算失败/资料非法 → 明确报错，无半成品数据（实测）。
