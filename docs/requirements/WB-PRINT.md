# WB-PRINT：运单打印数据接口 — 设计方案

- 状态：已确认
- 日期：2026-11-17
- 关联：ROADMAP P4（运单打印数据接口）；WB-001/002（运单模型与快照）；ORG-002（数据范围）；AUTH-001

## 1. 业务目标

为打印模板（P4 前端任务"运单打印模板"）提供只读数据接口：运单全量打印视图（单号/收发货人快照/货物件/费用/状态/条码载荷）。**只读、无状态副作用**。

## 2. 权限（首个 Waybills 域权限点）

- 新增 `waybill.read`（模块迁移 seed，固定 Guid 0000…0301，ORG-001 约定）。
- 访问规则：`waybill.read` 权限点 **且** 数据范围满足其一——租户级范围（TenantWideScope）、可访问始发网点、可访问目的网点（`CanAccessBranch` 实时校验，ORG-002 语义）。
- 跨租户 Id → 过滤器不可见 → 404。

## 3. 契约

| 端点 | 说明 |
|------|------|
| `GET /api/waybills/{id}/print` | 打印视图 DTO：运单号、支付方式、六类状态、收发货人快照、货物件列表（件号/货名/件数/重量/体积）、申报与固化费用合计、COD 金额、条码载荷（运单号）、创建时间 |

## 4. 测试计划

1. 有权限 + 网点范围 → 200 且字段完整（含快照费用合计与货物件）。
2. 无 `waybill.read` → 403。
3. 有权限但无两端网点范围且无租户级范围 → 403（数据范围）。
4. 跨租户 → 404。

## 5. 验收标准

- [ ] 打印数据完整且只读（不改状态）。
- [ ] 数据范围规则实测（网点范围/租户级范围）。
