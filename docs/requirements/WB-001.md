# WB-001：运单和货物件模型 — 设计方案

- 状态：已确认（六类状态的枚举值为**第一版**，各状态的流转随其业务任务交付；状态字段分离本身为已确认约束，AGENTS §6.1）
- 日期：2026-11-17
- 关联：ROADMAP P4/WB-001；AGENTS.md §6.1（状态分离）；docs/domain/glossary.md（状态独立性）；SEQ-001（单号格式）

## 1. 业务目标

建立运单（Waybill）与货物件（Waybill Package）的领域模型与持久化：**六类状态分离**（运单/货物/运输/交付/运费财务/COD）、一票多件、收发货人快照、租户内唯一运单号。本任务只交付**模型 + 状态机守卫 + 持久化**；开单命令、计价快照固化、运单事件时间线属 WB-002。

## 2. 六类状态（分离维护，禁止压缩成万能状态字段）

| 状态字段 | 枚举（第一版） | 初始值 | 后续流转归属 |
|----------|---------------|--------|--------------|
| 运单状态 | Draft=1, Confirmed=2, Cancelled=3 | Draft | WB-002 确认/取消命令 |
| 货物/仓储状态 | PendingReceive=1, Received=2, Sorted=3 | PendingReceive | P4 收货/入库/分拣任务 |
| 运输状态 | NotShipped=1 | NotShipped | P5 配载/发车/区段任务 |
| 交付/配送状态 | NotDelivered=1 | NotDelivered | P6 到货/交付/签收任务 |
| 运费财务状态 | Unpaid=1, PartiallyPaid=2, Settled=3 | Unpaid | P7 收款核销任务 |
| COD 状态 | None=1, PendingCollection=2, Collected=3, Settled=4, PaidOut=5 | 依 COD 金额：0→None，>0→PendingCollection | P8 COD 任务 |

- 签收（交付状态）不自动等于运费结清（财务状态）——字段独立，各自只由对应任务的领域方法流转。
- WB-001 只实现**运单状态**的流转守卫（确认/取消，WB-002 命令调用）；其余五类状态字段只落库初始值，不提前编造流转规则。

## 3. 领域规则（运单状态机，WB-001 实现）

- `Confirm`：仅 Draft → Confirmed；Confirmed/Cancelled 拒绝（幂等性不做，重复确认显式报错）。
- `Cancel`：Draft 或 Confirmed → Cancelled，且仅限运输状态 = NotShipped（已发运不可取消）；Cancelled 为终态，不可再取消/确认/恢复。
- 货物件仅在 Draft 可调整；Confirmed/Cancelled 后拒绝（P4 验收"已确认运单不能通过普通编辑接口篡改历史价格"的模型基础）。
- 创建守卫：起点网点 ≠ 终点网点；至少 1 个货物件；COD 金额 ≥0；收发货人快照必填；运单号非空（租户内唯一由数据库唯一索引兜底）。
- 货物件序号由工厂统一编为 1..N 连续（一票多件）；汇总口径 = Σ件（件数、重量、体积），供 WB-002 计价输入使用。

## 4. 表结构

```sql
CREATE TABLE waybills (
    id uuid PRIMARY KEY,
    tenant_id uuid NOT NULL,                    -- FK → tenants(id)；ux (tenant_id, id) 供复合外键
    waybill_no varchar(64) NOT NULL,            -- ux (tenant_id, waybill_no)，SEQ-001 生成（YB+网点码+期间+序号）
    origin_branch_id uuid NOT NULL,             -- 复合外键 → branches(tenant_id, id)
    dest_branch_id uuid NOT NULL,               -- 复合外键 → branches(tenant_id, id)
    customer_id uuid NOT NULL,                  -- 复合外键 → customers(tenant_id, id)
    route_id uuid NULL,                         -- 复合外键 → routes(tenant_id, id)；开单可不指定线路
    payment_type smallint NOT NULL,             -- 1=现付 2=到付 3=月结  ck
    waybill_status smallint NOT NULL,           -- 1/2/3    ck
    cargo_status smallint NOT NULL,             -- 1/2/3    ck
    transport_status smallint NOT NULL,         -- 1        ck
    delivery_status smallint NOT NULL,          -- 1        ck
    freight_status smallint NOT NULL,           -- 1/2/3    ck
    cod_status smallint NOT NULL,               -- 1..5     ck
    cod_amount numeric(18,2) NULL,              -- NULL/0 = 无代收
    total_amount numeric(18,2) NULL,            -- 计价固化时写入（WB-002）
    sender_name varchar(100) NOT NULL, sender_phone varchar(50) NOT NULL, sender_address varchar(500) NOT NULL,
    receiver_name varchar(100) NOT NULL, receiver_phone varchar(50) NOT NULL, receiver_address varchar(500) NOT NULL,
    remark varchar(500) NULL,
    created_at/by, updated_at/by, xmin
);

CREATE TABLE waybill_packages (
    id uuid PRIMARY KEY,
    tenant_id uuid NOT NULL,                    -- FK → tenants(id)
    waybill_id uuid NOT NULL,                   -- 复合外键 → waybills(tenant_id, id)
    package_no int NOT NULL CHECK (>= 1),       -- ux (tenant_id, waybill_id, package_no)
    cargo_name varchar(100) NOT NULL,           -- 货名
    quantity int NOT NULL CHECK (>= 1),         -- 本明细件数
    weight_kg numeric(12,3) NOT NULL CHECK (>= 0),
    volume_m3 numeric(12,4) NOT NULL CHECK (>= 0),
    remark varchar(500) NULL,
    created_at/by, updated_at/by, xmin
);
```

- 跨模块引用（网点/客户/线路）全部走**复合外键**，与 ORG-001/ROUTE-001 约定一致；不引用其他模块实体类。
- 发货人/收货人为**开单时快照**（文本固化，不外键到地址表，历史不受客户资料变更影响；P4"收发货人和地址快照"）。
- 计价快照（规则版本/输入/费用明细）属 WB-002，不在本表。

## 5. 模块边界

- 新模块 `Ltl.Modules.Waybills`（BASE-001 骨架），仅依赖 SharedKernel；网点/客户/线路以 Guid 引用。
- 无 HTTP 端点（与既有模块一致，随登录任务交付）。
- 运单号生成调用 SEQ-001 `IBranchSequenceService`（WB-002 开单命令接线，本任务仅建模字段）。

## 6. 测试计划

### 单元测试

- 创建守卫：空/超长运单号、起点=终点、空货物件、负 COD、空白收发货人、货物件非法值（件数 0、重量负、货名空）。
- 汇总口径：多件 Σ件数/重量/体积。
- 状态机：Draft→Confirm ✓；Confirmed/Cancelled 再确认拒绝；Draft/Confirmed→Cancel ✓；Cancelled 终态拒绝全部流转；已发运（运输状态非 NotShipped）取消拒绝。
- 货物件仅 Draft 可调整；Confirmed 后调整拒绝。
- COD 初始状态：金额 0 → None；>0 → PendingCollection。

### 集成测试（Testcontainers）

1. 迁移空库执行。
2. `(tenant_id, waybill_no)` 租户内唯一；跨租户允许同号。
3. 跨租户复合外键拒绝（货物件引用他租户运单、运单引用他租户网点/客户）→ `DbUpdateException`。
4. 过滤器隔离 + fail-closed。
5. 检查约束（非法 payment_type/status 拒绝）。
6. 同运单同件号唯一。
7. 金额/重量/体积精度往返（numeric(18,2)/12,3/12,4）。
8. xmin 乐观并发。
