# FIN-001：运费财务 — 设计方案

- 状态：已确认
- 日期：2026-11-17
- 关联：ROADMAP P7；AGENTS.md §6.5（应收/实收/未收分离；追加式流水；签收不等于结清）；WB-002（开单固化费用）；WB-PRINT

## 1. 业务目标

运费财务闭环：运单确认后自动生成应收；支持现付/到付收款（追加式）；部分收款和多次收款核销；退款冲正。**签收不自动等于结清**（AGENTS §6.1）。

## 2. 领域规则

- **应收（Receivable）**：运单确认时自动创建（金额 = 运单 TotalAmount）。一个运单一张应收。状态：Unpaid → PartiallyPaid → Settled（由核销驱动，不加人工改状态方法）。
- **收款（PaymentRecord，追加式）**：每次收款一条记录；金额 > 0；追加式不可修改删除；退款通过 RefundRecord 反向关联原收款。
- **核销（PaymentAllocation）**：收款与应收的核销关系分开保存；一笔收款可核销多张应收（目前一对一即可）；核销金额 = 收款金额；核销后更新应收已核销总额。
- **应收金额一致性**：应收 = 实收（Σ核销）+ 未收（amount − settled_amount）。
- **退款（RefundRecord，追加式）**：关联原收款；退款金额 ≤ 原收款金额 − 已退金额。
- **月结账单（CustomerStatement）**：按客户按期生成（列明细），确认后不可修改明细；关闭后不可再操作。本期实现生成和确认。

## 3. 表结构

```sql
CREATE TABLE receivables (
    id uuid PK, tenant_id uuid NOT NULL, waybill_id uuid NOT NULL,
    amount numeric(18,2) NOT NULL CHECK (> 0),
    settled_amount numeric(18,2) NOT NULL DEFAULT 0 CHECK (>= 0),
    status smallint NOT NULL,    -- 1=Unpaid 2=PartiallyPaid 3=Settled
    created_at/by, updated_at/by, xmin,
    ux (tenant_id, waybill_id)
);
CREATE TABLE payment_records (
    id uuid PK, tenant_id uuid NOT NULL,
    waybill_id uuid NOT NULL,    -- FK waybills
    amount numeric(18,2) NOT NULL CHECK (> 0),
    method smallint NOT NULL,    -- 1=Cash 2=OnDelivery 3=Monthly
    operator_user_id uuid NULL, note varchar(500) NULL,
    occurred_at timestamptz NOT NULL, created_at timestamptz NOT NULL, xmin
);
CREATE TABLE payment_allocations (
    id uuid PK, tenant_id uuid NOT NULL,
    payment_id uuid NOT NULL, receivable_id uuid NOT NULL,
    amount numeric(18,2) NOT NULL CHECK (> 0),
    created_at timestamptz NOT NULL,
    ux (tenant_id, payment_id, receivable_id)
);
CREATE TABLE refund_records (
    id uuid PK, tenant_id uuid NOT NULL,
    payment_id uuid NOT NULL, amount numeric(18,2) NOT NULL CHECK (> 0),
    reason varchar(500) NOT NULL, operator_user_id uuid NULL,
    occurred_at timestamptz NOT NULL, created_at timestamptz NOT NULL
);
```

## 6. 测试计划

1. 应收自动创建：运单确认 → 应收 Unpaid 生成（金额 = 运单 TotalAmount）。
2. 收款：全额收款 → 应收 Settled；部分收款 → PartiallyPaid；多次收款 → Settled。
3. 核销一致性：应收 settled_amount = Σ核销。
4. 退款：原收款 + 反向记录；退款后应收回退到 PartiallyPaid。
5. 签收不等于结清：签收后应收仍 Unpaid。
