## 契约约定（随 BASE-002 正式落地）

- REST 风格与明确的资源命名。
- 请求/响应一律 DTO，不得直接暴露 EF Core 实体。
- 统一错误格式：ProblemDetails；不泄露堆栈、SQL、密钥。
- 分页、排序、筛选建立一致约定。
- 关键命令（创建运单、收款、发车、交接、签收、COD 结算）具备幂等策略。
- 并发更新使用乐观并发控制。
- 所有业务 API 必须做认证、租户校验和权限校验；`tenant_id` 从服务端身份解析，不信任客户端提交。
- 金额、状态、时间、枚举值服务端验证。
